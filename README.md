# QIS System - 量化投资策略系统

自用量化策略研究与实盘系统，支持大类资产配置、CTA、多因子选股、ETF轮动、期权策略等。

│  │ (Risk Parity│ │(趋势跟踪)│ │ 选股     │ │ (动量)   │ │策略   ││

│                        Model Layer                               │

## 目录结构

```
qis_system/
├── config/          # 配置文件
├── data/            # 数据层（数据源、数据库、缓存）
├── models/          # 模型层
│   ├── allocation/  # 资产配置模型（Risk Parity, 均值方差）

├── backtest/        # 回测引擎
├── execution/       # 执行层（实盘接口）
├── utils/           # 工具函数
├── research/        # 研究 notebooks/scripts
└── tests/           # 测试
```

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置数据接口

在 `config/settings.py` 中配置 Tushare/AKShare token。

### 运行示例策略

```bash
python research/examples/test_data.py           # 数据层测试
python research/examples/test_allocation.py     # 资产配置策略
python research/examples/test_option_strategies.py  # 期权策略
```

## 策略类型

### 1. 大类资产配置
- **Risk Parity**: 风险平价模型，各资产风险贡献相等
- **Mean Variance**: 马科维茨均值方差优化

### 2. CTA
- **趋势跟踪**: 双均线、突破系统
- **波动率策略**: 基于波动率的信号

### 3. 多因子选股
- **价值因子**: PE、PB、股息率
- **成长因子**: 营收增长、利润增长
- **质量因子**: ROE、毛利率
- **动量因子**: 价格动量、RSI

### 4. ETF轮动
- **动量轮动**: 选择近期表现最好的ETF
- **风险调整轮动**: 考虑波动率的轮动

### 5. 期权策略
- **备兑开仓 (Covered Call)**: 持有标的+卖出看涨期权，震荡市增强收益
- **波动率套利 (Vol Carry)**: 日历价差、期限结构套利
- **希腊值管理**: Delta对冲、Vega敞口控制

## 开发规范

- 类型注解：所有函数必须添加类型注解
- 文档：重要类和方法必须添加 docstring
- 日志：使用 loguru 进行日志记录
- 配置：使用 pydantic 进行配置验证
